# Artwork provenance (Zadry fork)

Updated 2026-10-26. Every image below is generated by a script in this repository from the colour palette written in that script and one open-licence typeface,
**Inter** (SIL Open Font License 1.1, copyright The Inter Project Authors, https://github.com/rsms/inter; licence text in `mod/modules/core/OFL-Inter.txt`).
The typeface file itself is not distributed: only the rasterised pixels reach the mod. Nothing is read from, copied from or traced over the player's own artwork,
and no commercial or system typeface is used.

The previous tab-strip images and glyph atlases had no reproducible generator and came with dithering noise that suggested they were derived from the player's own
artwork; they were withdrawn from the tree and from every published template on 2026-10-26 (the originals are kept outside the repository, not distributed).

Regenerate with Pillow and Inter.ttf (Google Fonts, `ofl/inter`): run `build_tabs.py --font Inter.ttf` and, for each theme, `build_labels.py --font Inter.ttf --font-size 21 --theme dark|light`.
The tab strips are 180 x 50 RGB565 (18,000 bytes); the atlases are self-describing (`RX3GLYF1`) so the core reads glyph count and widths from the file.
The logo artwork is supplied by the user at build time and is not part of this table.
